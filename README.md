# Поиск фильмов — веб-версия

Веб-приложение для поиска фильмов в базе Sakila (MySQL) с логированием
поисковых запросов в MongoDB.

Проект построен на FastAPI, страницы формируются шаблонизатором Jinja2,
оформление — Bootstrap 5.

## Возможности

- Поиск по ключевому слову в названии фильма (совпадение в любой части названия)
- Поиск по жанру
- Поиск по жанру и диапазону годов выпуска
- Постраничный вывод результатов по 10 фильмов
- Сохранение всех поисковых запросов в MongoDB
- Статистика запросов: топ-5 популярных и 5 последних уникальных

## Структура проекта

```
films_web/
├── main.py                 маршруты FastAPI, обработчики форм
├── mysql_connector.py      подключение и запросы к MySQL
├── log_writer.py           запись логов в MongoDB
├── log_stats.py            агрегации статистики из MongoDB
├── local_settings.py       параметры подключения (не выкладывается в git)
├── requirements.txt        список зависимостей
└── templates/
    ├── base_page.html      общий каркас страниц
    ├── home.html           главная страница с формами поиска
    ├── films_table.html    таблица результатов с пагинацией
    ├── statistics.html     страница статистики
    └── error.html          страница сообщения об ошибке
```

Разделение по файлам: работа с базами данных отделена от формирования
страниц. Модули `mysql_connector.py`, `log_writer.py` и `log_stats.py`
не знают о вебе — они перенесены из консольной версии проекта без изменений.

## Установка

Требуется Python 3.10 или новее.

Установка зависимостей:

```
pip install -r requirements.txt
```

или вручную:

```
pip install fastapi uvicorn[standard] jinja2 python-multipart pymysql pymongo
```

## Настройка

Создайте файл `local_settings.py` в корне проекта:

```python
dbconfig = {
    "host": "адрес_сервера_mysql",
    "user": "имя_пользователя",
    "password": "пароль",
    "database": "sakila",
}

MONGODB_URL_WRITE = "mongodb://пользователь:пароль@адрес:27017/?authSource=ich_edit"
```

Файл содержит пароли, поэтому в репозиторий не добавляется.

## Запуск

```
uvicorn main:app --reload
```

После запуска приложение доступно по адресу http://127.0.0.1:8000

Флаг `--reload` перезапускает сервер при изменении файлов — удобно
при разработке, в рабочем окружении не используется.

## Как это устроено

**Пагинация.** Номер страницы передаётся в адресе (`?page=2`), из него
вычисляется `OFFSET` для SQL-запроса. Общее число страниц берётся из
отдельного запроса `COUNT(*)` без ограничения `LIMIT`.

**Логирование.** Запись в MongoDB выполняется только при новом поиске —
в обработчиках POST. Переходы между страницами результатов идут через GET
и в статистику не попадают. Поле `results_count` содержит полное количество
найденных фильмов, а не число строк на текущей странице.

**Безопасность запросов.** Все значения передаются в SQL через параметры
(`%s`), подстановка пользовательского ввода в текст запроса не используется.

**Обработка ошибок.** При недоступности MySQL показывается страница
с сообщением и кодом 503. Сбой MongoDB не прерывает поиск: запрос
выполняется, в консоль сервера выводится предупреждение о том, что лог
не записан.

## Пример работы

1. Открыть главную страницу — видны доступные жанры и диапазон годов в базе
2. Ввести ключевое слово, например `dog`, нажать «Найти»
3. Просмотреть результаты, при необходимости перейти на следующую страницу
4. Открыть «Статистика» и посмотреть популярные или последние запросы
